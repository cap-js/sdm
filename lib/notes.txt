SDM Attachments Service: Non-Draft Implementation Design & Documentation

Executive Summary

This document outlines the design and implementation of non-draft attachment functionality for the SDM (SAP Document Management) Attachments Service. The implementation extends the existing draft-based attachment system to support both draft and active (non-draft) attachment lifecycles, following CAP (Cloud Application Programming) framework patterns.
